# 提示音文件说明

此目录用于存放提示音文件。

## 需要的文件

- `notification.mp3` - 新消息提示音

## 如何获取提示音

1. 从免费音效网站下载提示音
2. 使用音频编辑软件创建简单的提示音
3. 使用系统自带的提示音

## 推荐的提示音来源

1. **Pixabay** - https://pixabay.com/sound-effects/
2. **Freesound** - https://freesound.org/
3. **Zapsplat** - https://www.zapsplat.com/

## 文件要求

- 格式：MP3
- 时长：0.5-2秒
- 音量：适中
- 风格：简洁、不刺耳

## 示例提示音

可以使用以下类型的提示音：
- 清脆的叮咚声
- 简短的铃声
- 柔和的提示音

将下载的 `notification.mp3` 文件放在此目录下即可。
