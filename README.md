# 🤖 NeonBotChat

基于 QQ 官方 Bot API 的 WebUI 机器人接管面板，支持真人接管 Bot 进行群消息收发。

## ✨ 功能

### 消息收发
- **实时消息**：WebSocket 推送，秒级同步群消息与私聊（C2C）消息
- **私聊支持**：私聊收发 / 富媒体 / 撤回（C2C API），界面「个人」化文案、昵称隐藏、会话头像复用
- **加群申请审批**：管理员群内待审批申请列表，一键同意 / 拒绝（可填原因 / 拉黑），新申请红点徽章提示
- **添加好友或群聊**：按 OpenID 一键添加会话，好友昵称与头像自动获取
- **手动接管**：通过 WebUI 直接以 Bot 身份发送消息
- **富媒体发送**：图片/视频/语音/文件/卡片通过图床一键发送，含大小限制
- **卡片消息**：表单填写图文卡片（msg_type=8），支持自定义 JSON
- **键盘消息**：Markdown + 键盘 JSON 组合
- **自定义消息**：完整 JSON payload（需 `developerMode: True`）
- **开发者模式**：`config.yaml` 控制高级功能可见性
- **富媒体接收**：图片 / 视频 / 语音 / 文件自动渲染播放
- **富媒体转发**：图片 / 视频 / 语音转发为真实媒体消息
- **Markdown 消息**：勾选 MD 发送，支持标题、粗体、斜体、代码、LaTeX 公式渲染
- **乐观更新**：发送消息即时显示气泡（含媒体预览），失败可重发
- **引用回复**：右键引用 → 输入栏上方显示引用预览（含缩略图）→ 发送带 `message_reference`
- **引用回复 UI**：毛玻璃引用框，显示发送人和内容，支持缩略图，Bot 图标自动适配
- **右键菜单**：引用、复制、转发、收藏、撤回、删除、多选
- **语音转文字**：语音消息下方显示 QQ 语音识别文本
- **消息布局**：头像 / 昵称 / 群角色徽章显示在气泡外，气泡内仅内容与引用
- **媒体免气泡**：纯图片 / 视频 / 语音消息不垫气泡底，直接展示（视频带圆形播放按钮封面）
- **图片/视频灯箱**：点击全屏浏览，左右切换（按钮 / 键盘 / 触摸滑动），滚轮 / 双指缩放并显示比例，图片视频混排翻页
- **日期分隔条**：聊天记录按天显示「今天 / 昨天 / 8月3日 周一」分隔线
- **拖拽发送**：文件拖进聊天区直接发送（与粘贴共用确认流程：预览 / 音频三选 / 文件提示）
- **URL 链接卡片**：消息内链接渲染为卡片，预加载网页标题 / 描述 / 图标（账号与安全可开关，关闭可避免 IP 泄露风险）
- **卡片消息渲染**：＋菜单「卡片消息」真正渲染为卡片（标题 / 描述 / 右侧图片 / 分割线 / 下划线链接，整体描边）
- **跳至最新消息**：新消息到达时若不在底部，输入框上方弹出「↓ 跳转至最新消息(XX条)」按钮（主题色底色），点击直达底部；滚回底部自动消失

### 消息管理
- **消息历史**：本地 SQLite 持久化，自动 5 秒刷新
- **撤回消息**：调用 QQ API 撤回；机器人是群管理员时自己的消息**随时可撤回**（不限 2 分钟）且可直接撤回群成员消息（生成系统气泡「你撤回了成员XXX的一条消息」）；文字消息支持「重新编辑」
- **删除消息**：本地删除单条或批量，不影响 QQ 端
- **多选模式**：右键进入多选，批量删除消息
- **清空记录**：支持清空单个群聊或全部聊天记录

### 会话管理
- **聊天列表**：自动识别群聊，预览显示「发送人: 内容」
- **备注名**：给群聊设置自定义备注名
- **添加群聊**：手动输入 group_openid 添加会话
- **置顶会话**：右键会话 → 置顶，置顶项主题色高亮排最前
- **消息免打扰**：右键会话 → 免打扰，未读气泡变灰
- **不显示会话**：右键会话 → 隐藏，搜索备注 / OpenID 找回（点开自动恢复）
- **@ 提醒**：被 @ 时会话列表显示红色 @ 徽标，点开即清除
- **群资料卡片**：点击群名弹出群头像 / 群名 / 完整 OpenID / 群标签 / 群简介 / 群分类，简介过长可点开全文；群名与人数自动获取、进群实时刷新
- **禁言管理**：右键成员头像 → 禁言 / 解除禁言（滚轮轮盘选时长，最多 30 天），1s 轮询状态自动切换菜单项，禁言提示入消息流（蓝色成员名可点击）

### 用户识别
- **Bot 标识**：Bot 消息自动标注 bot.svg 图标；机器人在群内的身份（群主 / 管理员 / 群员）徽章显示在标识前
- **角色徽章**：群主 / 管理员徽章，深浅主题各自配色
- **@提及转昵称**：`<@OpenID>` 自动替换为 @昵称
- **@ 提及列表**：输入框输入 `@` 弹出成员列表（实时过滤），点击插入 @昵称；右键成员头像 →「TA」直达
- **成员信息卡片**：点击消息头像或系统提示中的蓝色成员名，在点击位置弹出毛玻璃卡片（头像 / 昵称 / OpenID / 个性签名）
- **用户头像**：头像列显示在气泡外（无头像自动首字符占位），点击可查看大图
- **权限检查**：主动消息权限未授予时发送前弹窗确认；接收设置非全量时顶栏显示长条提示（毛玻璃、可关闭）

### 收藏系统
- 右键收藏任意消息（文字 / 图片 / 视频 / 语音）
- 收藏列表支持图片预览、视频播放、语音播放、转文字显示

### 查找聊天记录
- 设置 → 通用 → 查找聊天记录：**全局搜索**全部群消息
- 支持匹配消息内容、发送人昵称、附件文件名
- 结果标注群名、展示用户头像（Bot 消息显示自定义头像），点击跳转定位并高亮原消息

### 导出聊天记录
- 群聊设置 → 导出聊天记录：一键导出当前群全部消息为 **Markdown / JSON**
- 文件名自动使用群备注名

### 聊天记录卡片
- 收到 QQ 合并转发「群聊的聊天记录」自动解析为卡片：标题 + 前 4 条预览（单条 20 字符截断）
- 点击展开全部消息（气泡形式、无头像）

### 首页统计看板
- 未选择会话时默认显示统计看板：今日消息（收/发/累计）+ 活跃群 TOP5（近 7 天，带占比条）
- 毛玻璃卡片样式，支持导出周报（Markdown）
- 新增：近7天趋势柱状图、24小时活跃分布、媒体消息分布、会话参与度、活跃时段热力图（星期×小时）、发言达人 TOP5（带头像/占比条）

### 桌面通知
- 设置 → 通用开关，浏览器系统通知
- **@我 时强提醒**：即使正在查看该会话也会通知，通知点击直达会话

### UI / 个性化
- **SVG 图标**：全站 Lucide 风格 SVG，CSS 自动适配深浅色（含 ok / warning / favourite / bot / search 等状态图标）
- **自定义弹窗**：毛玻璃确认弹窗，替代浏览器原生对话框
- **深浅模式**：深色 / 浅色 / **自动**（跟随系统）三档切换，客户端独立
- **自定义主题色**：8 种预设色一键切换 + 取色器自定义 + 恢复默认，深浅主题通用（按钮 / 统计条 / 热力图 / 激活态自动跟随）
- **自定义背景**：上传图片作为聊天背景，填充整个页面
- **Bot 头像 / 简介**：服务器端存储，跨设备共享
- **透明度调节**：背景透明度 5%~100% 可调
- **毛玻璃效果**：侧边栏、顶栏、输入栏、气泡、按钮、设置导航栏、toast 均支持毛玻璃
- **Toast 提示**：居中方形毛玻璃卡片，图标在上文字在下，多提示队列串行显示
- **移动端适配**：≤768px 顶栏（BotChat logo / 头像+在线状态 / 昵称+个性签名）+ 底栏四页导航（主页 / 消息 / 收藏 / 设置），收藏与设置为独立页面；主页统计卡片不遮侧栏、3 张一页横向滑动分页；设置导航可折叠为纯图标（内容区更宽）
- **消息时间**：悬停 1 秒后气泡外显示时间，不占空间

### 设置面板
- **通用**：默认页面（主页 / 消息）+ 桌面通知开关 + 清空全部聊天记录
- **外观与显示**：显示模式（深浅 / 自动）+ 聊天背景（上传 / 透明度 / 清除）+ 自定义主题色
- **状态**：系统信息、CPU / 内存实时监控，进度条平滑动画
- **日志**：服务端控制台日志实时同步（最近 500 条，2 秒自动刷新）
- **账号与安全**：机器人信息（头像 / 昵称 / 简介由官方 API 自动获取，只读展示）+ 自动渲染链接卡片开关 + 退出登录
- **关于**：版本信息 + README 链接

### 侧侧栏与双视图
- **侧侧栏**（最左侧窄栏）：bot 图标 + 在线状态（头像右下角绿 / 红圆点）+ Bot 头像（点击更换）+ 主页 / 消息视图切换 + 收藏 / 设置
- **主页视图**：沉浸式统计看板（隐藏主侧栏，保留侧侧栏）
- **消息视图**：聊天界面（侧栏 + 会话列表，默认页「选择一个聊天」）
- 切换带动画：聊天区弹入弹出、主侧栏滑入滑出

### 安全
- **密码保护**：`webui-password` 启用后显示登录页验证
- **图床鉴权**：上传需 Bearer Token
- **用户协议**：初次访问强制阅读（10s 倒计时，每浏览器独立），协议内容在 `AGREEMENT.md`

### 配置
- 端口可配置（`webui-port`），默认 8080
- 外网访问开关（`enable-public`）
- 图床服务器独立配置（`file_server/config.yaml`）

## 🚀 快速开始

### 环境要求

- Python 3.10+
- Windows / Linux / macOS

### 安装

```bash
pip install qq-botpy aiohttp fastapi uvicorn psutil
```

### 配置

复制 `config.example.yaml` 为 `config.yaml` 并填入真实值：

```yaml
appid: "你的AppID"
secret: "你的AppSecret"
webui-port: 36336          # WebUI 端口，默认 8080
enable-public: false       # true 绑定 0.0.0.0 允许外网访问
webui-password: ""         # 访问密码，留空不启用

# 图床服务器连接（可选，用于富媒体发送）
file-server:
  public-url: "http://你的域名:36337"
  token: "你的Token"
```

### 启动

```bash
# 主程序
python init.py

# 图床服务器（可选，用于发送富媒体）
python file_server/file_server.py
```

浏览器打开 `http://127.0.0.1:36336`。

## 📁 项目结构

```
NeonBotChat/
├── init.py              # 主入口，启动 Bot + Web 服务
├── web_server.py        # FastAPI + WebSocket 后端
├── database.py          # SQLite 存储 + 消息去重
├── PatchMsg.py          # 补丁：群消息解析 + 附件提取 + 角色识别
├── PatchActiveMsg.py    # 补丁：主动发送 / 撤回 / URL 上传
├── PatchUserInfo.py     # 补丁：获取用户昵称 / 头像
├── config.example.yaml  # 配置文件示例
├── config.yaml          # 实际配置（含密钥，不提交 Git）
├── README.md            # 项目文档
├── templates/
│   └── index.html       # WebUI 前端（零框架依赖）
└── file_server/         # 图床服务器（独立项目）
    ├── file_server.py
    ├── config.yaml
    └── config.example.yaml
```

## 🛠 技术栈

- **后端**：Python FastAPI + WebSocket
- **前端**：原生 HTML/CSS/JS（零框架依赖）
- **存储**：SQLite
- **Bot SDK**：qq-botpy 1.2.1

## ⚠️ 注意事项

- `config.yaml` 中的 AppSecret 是敏感信息，请勿泄露或提交到公开仓库
- qq-botpy 官方 SDK 已长期未更新，本项目通过 Patch 模块补齐缺失功能
- 图片 / 视频 / 语音依赖 QQ 多媒体 CDN，链接可能有时效性
- 撤回消息有时限，超时无法撤回
- 语音消息使用 `voice_wav_url`（WAV 格式），非原始 AMR
- 图床服务器为独立项目，需单独启动，可与主程序部署在同一机器
- 富媒体发送需要图床服务器 + QQ API 支持，QQ 服务器需能访问图床公网 URL
